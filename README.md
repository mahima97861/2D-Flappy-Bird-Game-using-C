# 🐦 Flappy Bird Game in C

## 📌 Description
This is a simple Flappy Bird clone developed using the C programming language. The game runs in the console/terminal and demonstrates basic game logic, user input handling, and real-time movement.

## 🎮 Features
- Bird movement using keyboard input
- Random obstacle generation
- Score tracking system
- Collision detection
- Simple and interactive gameplay

## 🛠️ Technologies Used
- C Programming Language
- Console-based graphics

## ▶️ How to Run
1. Open terminal
2. Compile the code:
   gcc flappy.c -o flappy
3. Run the program:
   ./flappy


## 🎯 Learning Outcomes
- Understanding of loops and conditions
- Real-time input handling
- Basic game development logic in C
