# 🐦 2D Flappy Bird Game using C

## 📖 Overview

**2D Flappy Bird Game** is a console-based recreation of the popular Flappy Bird game developed using the **C Programming Language**. The project demonstrates fundamental game development concepts such as real-time user interaction, obstacle generation, collision detection, score tracking, and game loop implementation.

This project was built as part of my **BCA Semester 1 learning journey** to strengthen my understanding of C programming, problem-solving, and basic game development principles.

---

## 🎮 Gameplay

The objective of the game is simple:

* Control the bird using keyboard input.
* Navigate through randomly generated obstacles.
* Avoid collisions with pipes and boundaries.
* Survive as long as possible.
* Achieve the highest score.

---

## ✨ Features

### 🐦 Bird Controls

* Responsive keyboard-based movement.
* Smooth upward and downward motion simulation.

### 🚧 Dynamic Obstacles

* Randomly generated pipe positions.
* Increasing challenge as gameplay progresses.

### 🎯 Score Tracking

* Real-time score calculation.
* Displays player performance during gameplay.

### 💥 Collision Detection

* Detects collisions with obstacles.
* Ends the game when the bird crashes.

### ⚡ Real-Time Gameplay

* Continuous game loop execution.
* Interactive console-based gaming experience.

### 🖥️ Lightweight & Fast

* Runs directly in the terminal/console.
* No external libraries required.

## ⚙️ Installation & Execution

### Step 1: Clone the Repository

```bash
git clone https://github.com/your-username/2D-Flappy-Bird-Game-using-C.git
```

### Step 2: Navigate to the Project Folder

```bash
cd 2D-Flappy-Bird-Game-using-C
```

### Step 3: Compile the Program

```bash
gcc flappy.c -o flappy
```

### Step 4: Run the Game

#### Linux / macOS

```bash
./flappy
```

#### Windows

```bash
flappy.exe
```
